# Sherdor Games Launcher

Внутренний WPF-лаунчер для установки, обновления и запуска нескольких Windows-игр. Проект работает на .NET 8.

## Добавление игры

Нажмите **«Добавить игру»** в правом верхнем углу библиотеки и заполните:

- название и описание игры;
- имя отдельной папки игры;
- имя `.exe` игры внутри ZIP-архива;
- ссылку на текстовый файл версии;
- ссылку на ZIP-архив сборки;
- логотип и обложку;
- любое количество дополнительных изображений для слайд-шоу.

После нажатия **«Добавить»** лаунчер сам:

1. создаёт отдельную папку игры;
2. копирует логотип и обложку в `images/games`;
3. добавляет игру в `launcher-settings.json`;
4. открывает окно новой игры и начинает её установку.

Обычные публичные ссылки Google Drive на `Version.txt` и ZIP преобразуются в прямые ссылки автоматически.

## Работа библиотеки

Щелчок по карточке открывает отдельное окно игры с обложкой, логотипом, описанием, версией и кнопкой запуска.

Если для игры выбраны изображения слайд-шоу, они автоматически меняются каждые пять секунд. Кадры также можно переключать вручную стрелками. Для старых игр без слайд-шоу используется обычная обложка.

- если игра не установлена, доступна кнопка **«Установить»**;
- если на сервере появилась новая версия, внутри окна появляются отдельные кнопки **«Играть»** и **«Обновить»**;
- обновление загружается только после нажатия **«Обновить»**;
- если версия актуальна, появляется кнопка **«Играть»**;
- если сервер недоступен, уже установленную игру можно запустить офлайн.

Каждая игра устанавливается в свою папку и имеет отдельный локальный файл версии. При ошибке обновления старая рабочая версия восстанавливается.

## Редактирование игры

В окне игры нажмите **«Редактировать»**. Форма откроется с уже заполненными данными. Можно изменить название, описание, папку, исполняемый файл, ссылки, логотип и обложку, а также добавить новые изображения к существующему слайд-шоу. Кнопка **«Очистить»** убирает слайды из настроек игры. Удалять и повторно добавлять игру не требуется.

В поле **«Ссылка на YouTube-видео»** можно указать обычную ссылку `youtube.com/watch`, короткую ссылку `youtu.be` или ссылку YouTube Shorts. Видео появится во встроенном плеере над описанием игры. Переходы во внешнее окно YouTube заблокированы; при ошибке доступна повторная загрузка внутри лаунчера.

Кнопки **«Добавить игру»** и **«Редактировать»** доступны только в Debug-сборке. В Release-сборке они автоматически скрываются от обычных пользователей.

## Формат версии и архива

Файл версии содержит только номер, например:

```text
1.2.3
```

ZIP может содержать файлы игры прямо в корне или внутри одной дополнительной папки. Лаунчер найдёт указанный `.exe` и установит сборку в выбранную папку игры.

## Сборка

```powershell
dotnet build GameLauncher.sln --configuration Release
```

Для публикации автономного Windows-приложения:

```powershell
dotnet publish GameLauncher/GameLauncher.csproj --configuration Release --runtime win-x64 --self-contained true
```
